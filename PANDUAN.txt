SKP HARIAN — PANDUAN PEMASANGAN (multi-pegawai)
==============================================

Isi folder
  index.html     Halaman pegawai: Dashboard kerja harian, Upload Dokumen
                 (Bukti Dukung), Profil
  input.html     Aplikasi "Catat SKP" gaya WhatsApp (dipasang di HP)
  admin.html     Halaman admin: Dashboard monitoring pengisian + kop surat,
                 Pengguna (tambah / ubah / hapus, reset password)
  template-bukti-dukung.docx
                 Cetakan dokumen Bukti Dukung (dari dokumen kantor). Untuk mengganti
                 tampilan dokumen, ganti berkas ini — jangan ubah tulisan {{...}} di dalamnya.
  config.js      <- DIISI alamat & kunci database (langkah 2)
  setup.sql      Skrip pembuat database (langkah 1)
  common.js, docx.js, excel.js, sw.js, manifest-*.json, icons/, vendor/  (jangan dihapus)
  vendor/xlsx.full.min.js  Pustaka SheetJS untuk membaca/menulis Excel (lisensi Apache-2.0)

Cara kerja
  - Website (file HTML) disimpan di GitHub Pages — gratis.
  - Data pegawai, kegiatan, dan foto bukti disimpan di database Supabase — gratis.
  - Pegawai masuk dengan NIP LAMA + password; NIP BARU (18 digit) tampil di dokumen.
    Akun admin cukup nama + username + password. Database hanya mengizinkan
    pegawai membaca dan mengubah datanya sendiri. Admin mengelola daftar
    pegawai, tetapi juga TIDAK bisa melihat isi pekerjaan pegawai lain.


LANGKAH 1 — Buat database di Supabase (± 10 menit, sekali saja)
  1. Buka https://supabase.com -> Start your project -> daftar (bisa pakai akun GitHub).
  2. New project: isi nama (mis. skp-harian), buat Database Password (simpan baik-baik),
     Region: Southeast Asia (Singapore) -> Create new project. Tunggu ± 2 menit.
  3. Menu kiri "SQL Editor" -> New query -> buka setup.sql, salin SEMUA isinya,
     tempel -> klik Run. Harus muncul "Success. No rows returned".
  4. Menu "Authentication" -> "Sign In / Providers" (atau Providers -> Email):
       - "Confirm email"  -> MATIKAN (OFF), lalu Save.
       - "Allow new users to sign up" -> biarkan ON (dipakai admin saat menambah pegawai).

LANGKAH 2 — Isi config.js
  1. Di Supabase: Project Settings (ikon gerigi) -> API / "Data API" & "API Keys".
  2. Salin "Project URL"  -> tempel ke SUPABASE_URL di config.js
     Salin kunci "anon public" (eyJ...) atau "publishable" (sb_publishable_...)
       -> tempel ke SUPABASE_ANON_KEY.
     JANGAN gunakan kunci "service_role" / "secret".
  3. Ubah NAMA_INSTANSI bila perlu. EMAIL_DOMAIN biarkan saja.

LANGKAH 3 — Unggah ke GitHub Pages
  1. Masuk github.com -> New repository (mis. skp-harian), Public -> Create.
  2. "uploading an existing file" -> seret SEMUA isi folder ini (termasuk folder icons)
     -> Commit changes.
  3. Settings -> Pages -> Source: "Deploy from a branch", Branch: main, folder / (root) -> Save.
  4. Tunggu 1–2 menit. Alamatnya: https://NAMA-AKUN.github.io/skp-harian/

LANGKAH 4 — Admin pertama & daftar pegawai
  1. Buka alamat tadi. Di halaman masuk klik "Penyiapan awal: daftarkan admin pertama",
     isi nama, username (mis. admin), password. Akun ini menjadi admin.
     (Tautan ini hilang otomatis setelah admin pertama terdaftar.)
  2. Buka menu "Admin" -> "+ Tambah pengguna":
       Pegawai: nama lengkap, NIP lama (untuk masuk), NIP baru, jabatan, unit kerja, password awal.
       Admin  : nama, username, password.
     Sampaikan NIP lama + password awal ke pegawai.
     Banyak pegawai sekaligus: Pengguna -> "Impor Excel" -> unduh template -> isi
     (kolom NIP sudah berformat Teks; jangan diubah ke angka) -> pilih file -> periksa
     pratinjau -> "Tambahkan". Password yang dikosongkan dibuat otomatis; setelah selesai
     klik "Unduh daftar akun & password" untuk dibagikan ke pegawai.
     Catatan: Supabase membatasi jumlah pendaftaran akun per beberapa menit. Bila
     batas tercapai, aplikasi otomatis menunggu ±1 menit lalu melanjutkan. Untuk impor
     besar, batas ini bisa dinaikkan di Supabase -> Authentication -> Rate Limits.
  3. Pegawai memilih BIDANG setiap kali mencatat. Kegiatan tiap bidang menjadi satu
     dokumen Bukti Dukung.
  4. Ubah = ikon pensil (termasuk reset password, ganti peran, nonaktifkan).
     Hapus = ikon tempat sampah (akun + semua kegiatannya terhapus permanen).
  5. Kop surat: Admin -> Dashboard -> "Unggah kop (.docx)". Kop berlaku untuk dokumen
     Bukti Dukung semua pegawai. Tanpa unggahan dipakai kop bawaan cetakan.
  6. Monitoring: Admin -> Dashboard menampilkan siapa yang sudah/belum mengisi hari ini
     dan jumlah kegiatan per pegawai per bulan (admin tidak melihat isi kegiatan).

LANGKAH 5 — Pegawai memasang di HP
  1. Buka https://NAMA-AKUN.github.io/skp-harian/input.html di Chrome HP, masuk dengan NIP lama.
  2. Menu ⋮ -> "Instal aplikasi" / "Tambahkan ke layar utama"
     (iPhone: Safari -> Bagikan -> "Tambah ke Layar Utama").
  3. Pegawai sebaiknya mengganti password sendiri dan melengkapi jabatan: menu Profil.

Catatan
  - Aplikasi memerlukan internet saat menyimpan (data langsung masuk database).
  - Paket gratis Supabase: database 500 MB, foto 1 GB — cukup untuk puluhan pegawai
    bertahun-tahun karena foto otomatis dikecilkan (± 150 KB/foto).
    Proyek gratis dijeda bila 7 hari tidak dipakai sama sekali; aktifkan lagi
    dari dashboard Supabase (data tidak hilang).
  - Pegawai lupa password: admin -> ikon pensil -> isi "Reset password".
  - Mengubah isi setup.sql tidak diperlukan; skrip aman dijalankan ulang.

Mencatat & mengunduh Bukti Dukung
  - Menu Input: pilih BIDANG, ketik uraian kegiatan, lampirkan foto, kirim.
  - Banyak kegiatan sekaligus: ikon tabel di menu Input, atau tombol "Impor Excel" di
    Dashboard -> unduh template -> isi Tanggal, Jam, Bidang, Uraian -> pilih file ->
    periksa pratinjau -> Simpan. Foto ditambahkan setelahnya lewat ikon pensil.
    "Ekspor Excel" di Dashboard mengunduh kegiatan bulan yang dipilih.
  - Menu Upload Dokumen -> pilih triwulan (dan bidang).
    Muncul daftar bidang (1 dokumen per bidang): unduh satu per satu (.docx) atau
    "Unduh semua" (.zip).
    Setiap dokumen: Nama, NIP baru, RK & IKI dikosongkan (diisi petugas), [CAPAIAN]
    berisi uraian kegiatan, lalu foto bukti.

MEMPERBARUI VERSI (bila sebelumnya sudah memasang versi lama)
  1. Supabase -> SQL Editor -> jalankan setup.sql yang baru (data lama tetap aman).
  2. GitHub -> unggah semua berkas baru (termasuk template-bukti-dukung.docx),
     KECUALI config.js milik Anda yang sudah berisi kunci — jangan ditimpa.
